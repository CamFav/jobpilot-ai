# Architecture decision records

Architecture decision records (ADRs) capture decisions that materially affect the codebase and their context. Add a new numbered ADR when a decision is durable and non-trivial; do not rewrite an accepted ADR to hide a later reversal.

Suggested status values: `proposed`, `accepted`, `superseded`, `deprecated`.
