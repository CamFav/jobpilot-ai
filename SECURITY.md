# Security policy

## Reporting a vulnerability

Please do not report suspected security vulnerabilities through public GitHub Issues. Until a private reporting channel is configured in GitHub, contact the repository owner privately through the contact method listed on the GitHub profile and include:

- a concise description of the issue;
- affected component and version or commit;
- safe reproduction steps;
- potential impact.

Do not include credentials, access tokens, personal documents, or sensitive user data in the report.

## Scope

This policy applies to code and configuration in this repository. Third-party job platforms and AI providers have their own security reporting channels.
